# Bring-up presentation media

[bringup.png](bringup.png) is the exact 400 × 300 initial diagnostic pattern from
the shared `rlcd_frame_draw_test` function used by the bring-up firmware. It shows
the asymmetric orientation marker, text, stripes, checkerboards, square and
initial counter. It is a native screen render, not a device photograph.

Follow the [shared regeneration guide](../../../../docs/media/README.md).
[manifest.json](manifest.json) records input/output hashes. The
[dated bring-up receipt](../../../../docs/bringup.md) keeps build, USB, panel
runtime and physical observations separate.
