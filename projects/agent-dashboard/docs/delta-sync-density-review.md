## Private storage work

Mesh may prototype private packed hash-node storage now, on its isolated G1
branch, using the current normalization and public callback/query interfaces.
This implementation choice needs no further general go-ahead. It must preserve
canonical keys and values, expected-old checks, all independent logical table
and cohort roots, sparse visits, lookup/enumeration and revocable handle behavior.

Charge backing pages, unused slots, free lists, generations, references,
indexes and temporary construction before allocation under the same heap cap.
Canonical key/value and encoded input/output/stage/journal/pin storage still
consume the one shared encoded budget, including when held in pages or slices.
Packing must not reclassify those bytes out of the encoded cap. Shared physical
storage counts once within each applicable cap; independent copies count again.

Each live node owns its actual outgoing edges. Freeing a node releases those
edges promptly even when another node keeps its backing page allocated; that
remaining page capacity stays charged. Handle generations and arena epochs
must reject stale-slot/ABA reuse. Failed stages and repeated close/cancellation
must reclaim their own nodes, reservations and references with GC disabled.
Old material reclamation stays outside compact nonce confirmation.

Keep the existing independent root oracle and adversarial/ordering vectors.
Re-run the structural density diagnostic against the same logical input, with
current/predecessor/stage and rejection peaks. Then qualify the actual Agent
full/active and selected-host aggregate cases, sparse work, CPU, heap/RSS and
plateau under the original matrix. The two independent views do not redefine
Agent selection policy. A prototype fit is not installed-pair acceptance.

expansion, storage and roots. The four semantic callbacks retain their roles.
The agreed compact path avoids eager per-field public operation rosters.

Dependent shared implementation may proceed through that exact interface. Its
implementation and remaining schema/qualification work must preserve:

- The injected codec/descriptor and owned plan/iterator lifetimes, with explicit
  expanded versus compact negotiation and strict raw validation.
- Before-state aliases for removals and expected-old checks, provisional new
  aliases for inserts/reinsertion, and the semantic callback's independently
  derived final alias index. Reject conflicting definitions and stale births.
- Exact mask absence/zero/bit/duplicate rules; old masks checked against admitted
  before cells; public provisional mask reads without authority. Field-token
  changes with unchanged masks must yield the same logical cells and roots as
  explicit changes. Failure rolls back every provisional alias, cell and index.
- Public input reservation/seal/consume/close, including baseline, batches,
  watches and head/control. Reserve before receive/copy/parse; retain charges
  through transfer, rejection, cancellation and slow peers. Byte ownership alone
  supplies neither material admission nor proof authority.
- Joint exact join/token/alias/mask/root/rejection vectors, allocation bounds and
  descriptor identities. No private graph access or hidden roster restoration.

Observer's streamed one-row semantic admission remains useful with either
storage representation. Native codec plans must not reintroduce full detached
body/observation rosters around that callback. Other independent owning-layer
